
# Student Task Manager – User Guide

## Starting the Application

Run:

    py main.py

## Adding a Task

Select option 1 and enter a task title.

Empty titles are rejected.

## Displaying Tasks

Select option 2 to view all tasks and their status.

## Completing a Task

Select option 3 and enter the task ID.

## Deleting a Task

Select option 4 and enter the task ID.

## Exiting

Select option 5 to close the application.
