# Student Task Manager

A Python console application for managing student tasks.

## Features

- Add new tasks
- Display all tasks
- Mark tasks as completed
- Delete tasks using task IDs
- Validate empty task titles

## Requirements

- Python 3.11 or later
- Git

## Installation

Clone the repository:

    git clone https://github.com/fajar-sajid/studenttaskmanager.git

Open the project:

    cd studenttaskmanager

## Usage

Run the application:

    py main.py

Choose an option from the menu:

1. Add Task
2. Display Tasks
3. Complete Task
4. Delete Task
5. Exit

## Running Tests

Run automated tests:

    py -m unittest discover -s tests -v

## GitHub Actions

Automated tests run whenever code is pushed to main
or a Pull Request is opened targeting main.
